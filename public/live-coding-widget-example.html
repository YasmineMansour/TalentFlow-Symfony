Intégrez le live coding collaboratif dans vos applications

🧪 Démonstration

Exemple d'utilisation interactive

Le widget flottant devrait apparaître dans le coin inférieur droit si vous avez fourni un entretienId. Cliquez sur le bouton pour ouvrir une popup live coding.

📦 Installation et usage

Étape 1 : Charger le script

<script src="http://127.0.0.1:8000/js/live-coding-widget.js"></script>

Étape 2 : Initialiser le widget

TalentFlowLivecoding.init({ entretienId: 34, // ID de l'entretien position: 'bottom-right', // Position: bottom-right, bottom-left, top-right, top-left title: '💻 Code', // Texte du bouton tooltip: 'Ouvrir Live Coding' // Tooltip au survol });
💡 Astuce : Le widget détecte automatiquement l'ID dans l'URL avec le paramètre ?entretienId=34

⚙️ Options de configuration

Option Type Défaut Description
entretienId number null ID de l'entretien (requis)
position string 'bottom-right' Position du widget: bottom-right, bottom-left, top-right, top-left
baseUrl string 'http://127.0.0.1:8000' URL de base du serveur TalentFlow
title string '💻 Code' Texte du bouton flottant
tooltip string 'Ouvrir Live Coding' Texte au survol du bouton

🔌 API JavaScript

Méthodes disponibles

init(config)
// Initialiser le widget avec une configuration TalentFlowLivecoding.init({ entretienId: 34 });
open(entretienId)
// Ouvrir directement une session live coding TalentFlowLivecoding.open(34);
destroy()
// Supprimer le widget TalentFlowLivecoding.destroy();
getConfig()
// Récupérer la configuration actuelle var config = TalentFlowLivecoding.getConfig(); console.log(config.entretienId);

💻 Exemples d'intégration

Microsoft Teams

<!-- Dans votre page Teams-hosted --> <script src="http://127.0.0.1:8000/js/live-coding-widget.js"></script> <script> // Auto-détecte l'entretien ID depuis les paramètres de query const params = new URLSearchParams(window.location.search); const entretienId = params.get('entretienId'); if (entretienId) { TalentFlowLivecoding.init({ entretienId: parseInt(entretienId), position: 'bottom-right' }); } </script>

Page HTML statique

<!DOCTYPE html> <html> <head> <script src="http://127.0.0.1:8000/js/live-coding-widget.js"></script> </head> <body> <h1>Ma réunion de travail</h1> <p>Discutez et programmez ensemble...</p> <script> // Initialiser le widget au chargement document.addEventListener('DOMContentLoaded', () => { TalentFlowLivecoding.init({ entretienId: 34, position: 'bottom-right' }); }); </script> </body> </html>

Communication avec la popup

// Écouter les événements de la popup window.addEventListener('message', (event) => { if (event.data.type === 'TALENTFLOW_LIVE_CODING_READY') { console.log('Live Coding démarré pour:', event.data.entretienId); // Faire quelque chose quand le live coding est prêt } });

Endpoint Méthode Description
/live-coding/test GET Diagnostic de l'API (public)
